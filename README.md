Logistic Regression Classification

## Project Overview
This project demonstrates the implementation of the Logistic Regression algorithm for binary classification using Python and Scikit-learn. It covers the complete machine learning workflow, from data preprocessing to model evaluation.

- Train-Test Split
- Logistic Regression Model
- Model Training
- Prediction
- Accuracy Evaluation
- Confusion Matrix
- Classification Report
